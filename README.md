# Sentiment Analysis using NLP

## 📌 Project Overview

This project performs **sentiment analysis on text data** using Natural Language Processing (NLP) and Machine Learning techniques.

The goal is to analyze a given text and identify its sentiment, such as **Positive, Negative, or Neutral**.

## 🎯 Objectives

* Clean and preprocess text data
* Convert text into a suitable format for machine learning
* Analyze the sentiment of text
* Build a sentiment prediction model
* Evaluate the model performance

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* NLTK
* Scikit-learn
* Natural Language Processing (NLP)

## 🔄 Project Workflow

1. Load the dataset
2. Perform data cleaning
3. Text preprocessing
4. Tokenization and stopword removal
5. Convert text into numerical features
6. Train the machine learning model
7. Predict sentiment
8. Evaluate the model

## 📂 Project Files

* `emotional_analyzer.py` – Python script for sentiment analysis
* `data.csv` – Dataset used for the project
* `.gitignore` – Files and folders excluded from Git tracking

## 📊 Output

The model analyzes the given text and predicts its corresponding sentiment.
